# Quantum ZJU CAS account plugin

Plugin ID: `quantum.zju.plugin.cas`. Uses Quantum SDK **0.3.0-rc.3**.

Provides the ZJU account connection and service-bound CAS tickets. Individual university systems are integrated by external plugins.
